# Despliegue de DeadMoon Tattoo

## Opción 1: Vercel
1. Crea un repositorio en GitHub y sube esta carpeta.
2. Entra a https://vercel.com y selecciona "Add New Project".
3. Importa el repositorio.
4. Mantén la configuración por defecto y despliega.
5. Añade el dominio: deadmoontattoo.scisenselab.com.

## Opción 2: Cloudflare Pages
1. Crea un repositorio en GitHub y sube esta carpeta.
2. Entra a Cloudflare Pages y selecciona "Create project".
3. Conecta GitHub y selecciona este repositorio.
4. Elige la carpeta raíz y despliega.
5. Añade el dominio personalizado: deadmoontattoo.scisenselab.com.

## DNS recomendado
- Tipo: A
- Nombre: @ o www
- Valor: 18.219.34.245
- Proxied: Activado
